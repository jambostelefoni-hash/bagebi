# ბაღების პლატფორმა

საბავშვო ბაღების რეგისტრაციის, ადგილების, მომლოდინეთა რიგის და ყოველდღიური დასწრების მართვის სისტემა.

## შესაძლებლობები

- გაერთიანების ადმინისტრატორისა და თითო ბაღის დირექტორის იზოლირებული წვდომა;
- 2–6 წლის ბავშვების რეგისტრაცია, ტევადობის ტრანზაქციული კონტროლი და მომლოდინეთა რიგი;
- ვადიანი ელფოსტის ბმულით ადგილის მიღება ან უარყოფა;
- ყოველდღიური სახელობითი დასწრება და Excel/PDF-ბეჭდვის ანგარიშები;
- 10 ზედიზედ ან თვეში 15 არასაპატიო სამუშაო დღის გაცდენაზე ავტომატური შეჩერება;
- private დოკუმენტის ატვირთვა და გაერთიანების მიერ აღდგენის დამტკიცება;
- მართვადი სამუშაო კალენდარი, აუდიტის ისტორია და ელფოსტის ფონური რიგი.

## განთავსება

1. შექმენით production ბაზის სრული სარეზერვო ასლი.
2. დააყენეთ PHP, Composer, Node.js და MySQL; შეავსეთ `.env`.
3. გაუშვით `composer install --no-dev --optimize-autoloader`, `php artisan migrate --force` და frontend production build.
4. queue worker გაუშვით მუდმივ პროცესად: `php artisan queue:work --tries=3`.
5. cron-იდან ყოველ წუთს გაუშვით `php artisan schedule:run`; რიგი მუშავდება ყოველ 10 წუთში, დასწრება კი ყოველდღე 20:00-ზე.
6. მიუთითეთ SMTP პარამეტრები და `QUEUE_CONNECTION=database`.

პირველ production გაშვებამდე migration შეამოწმეთ ბაზის ასლზე. არსებული `is_administrator=1` მომხმარებლები გარდაიქმნებიან გაერთიანების ადმინისტრატორებად; სხვა მომხმარებლებს უნდა მიებას შესაბამისი ბაღი.

## უსაფრთხოება

აღდგენის დოკუმენტები ინახება `storage/app/reinstatement-documents`-ში და არ უნდა გამოქვეყნდეს symlink-ით. პირადი ნომრები და საკონტაქტო მონაცემები audit log-ში არ იწერება. საჯარო მოთხოვნები დაცულია rate limit-ითა და ვადიანი token-ებით.
