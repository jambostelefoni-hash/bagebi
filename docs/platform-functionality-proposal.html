09 / ინტეგრაციები

ელფოსტა და SMS — მომწოდებლისგან დამოუკიდებელი მიდგომა

შეტყობინებების ლოგიკა შეიძლება დაუკავშირდეს დამკვეთის მიერ შერჩეულ სახელმწიფო ან კომერციულ სერვისს ძირითადი ბიზნესფუნქციების გადაწერის გარეშე.

ელფოსტის შეტყობინებები

საჭიროა SMTP/API

გათვალისწინებულია შეტყობინებები რეგისტრაციის, რიგში ჩასმის, შეთავაზების, სტატუსის ცვლილების, შეჩერებისა და აღდგენის ეტაპებზე.

  • ფონური რიგი და განმეორებითი მცდელობები
  • გაგზავნის სტატუსისა და შეცდომის ისტორია
  • SMTP ან API მომწოდებლის ჩანაცვლების შესაძლებლობა

SMS შეტყობინებები

საჭიროა პროვაიდერის API

SMS არხის ჩართვა შესაძლებელია სახელმწიფო/მუნიციპალური სერვისის ან მობილური ოპერატორის ტექნიკური მონაცემების მიღების შემდეგ.

  • Sender ID-ის მხარდაჭერა
  • იგივე მოვლენები, რაც ელფოსტისთვის
  • პროვაიდერის შეცვლა adapter-ის დონეზე
გასააქტიურებლად დამკვეთისგან საჭიროა: ოფიციალური დომენი და გამგზავნის მისამართი, SMTP/API მონაცემები, SMS პროვაიდერის დოკუმენტაცია, Sender ID, ლიმიტები და უსაფრთხოების მოთხოვნები. პირველადი რეგისტრაციის მრავალდოკუმენტიანი ატვირთვა შეიძლება დაემატოს ცალკე მოთხოვნად; ამჟამად უსაფრთხო ატვირთვა გამოიყენება რეგისტრაციის აღდგენის პროცესში.
